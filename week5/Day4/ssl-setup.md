# SSL Setup Using mkcert and NGINX

## Overview

This setup enables **HTTPS in a local development environment** using a trusted SSL certificate generated by **mkcert**.  
**NGINX** is used as a reverse proxy to terminate TLS, while backend services continue to communicate over **HTTP** within the Docker network.

This approach closely mirrors how HTTPS is handled in production systems.

---

## Objectives

- Enable HTTPS locally with a trusted certificate
- Simulate a production-like domain
- Terminate TLS at NGINX
- Keep backend services running on HTTP
- Verify secure communication via browser trust indicators

---

A custom local domain is used to simulate a production environment.
